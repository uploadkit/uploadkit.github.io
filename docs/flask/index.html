Flask

Thin integration over Core. Adapts Werkzeug FileStorage, maps UploaderError to JSON, and resolves storage from app.config. Pair with uploadkit-security. Python 3.10+, Flask 3.0+.

Install

Adapter glue

Policy setup, validators, UploaderError, and the JSON response shape are shared — see Common patterns. as_uploadable() maps FileStorage.filename → Core name (form-field name is not the upload name).

Uses get_storage_provider() → Boto3S3Storage (AWS S3 or MinIO), as_uploadable(), and json_error_response().

Set UPLOADKIT_STORAGE_PROVIDER to a callable or dotted path. AWS: leave AWS_S3_ENDPOINT_URL unset. MinIO: set it to your endpoint.

Public API

  • as_uploadable — adapt werkzeug.FileStorage for sync Uploader
  • get_storage_provider / ImproperlyConfiguredUploadKit — resolve factory from current_app.config
  • json_error_response / status_for_error / error_payload — map Core errors to Flask JSON
